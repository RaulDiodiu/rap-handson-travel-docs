# Part 10a - CDS Custom Entity 

## Introduction.
A CDS custom entity is a non-SQL CDS entity with a custom query implemented in an ABAP class. In other words, a CDS custom entity does not have an SQL view to select data from a database. Instead, the custom entity specifies an ABAP class that implements the query. 
using annotation @ObjectModel.query.implementedBy: 'ABAP:<Query_Impl_Class>'.

A custom entity give us the oportunity to provide the data using the ABAP Classes.  
Here are some basic scenarios where we can used a custom entity:
- the data is not stored in a databased table and an cds cannot be used to retrieve the data.
- the data is provided by a Function Module (FM).
- the data it's provided from an external systems ( odata service ).   

There are more scenarios, for additional information check SAP Help [CDS Custom Entity](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm?file=abencds_custom_entities.htm) . 


The syntax of a CDS custom entity is the following:
```abap
@EndUserText.label: 'EndUserText'
@ObjectModel.query.implementedBy: 'ABAP:<Query_Impl_Class>'

[define] [root] custom entity CustomEntityName

     [ with parameters
          ParamName : dtype [, ...]    ]

{
        [@element_annot]
   [key] ElemName : dtype;
         ElemName : dtype; 
...
   [ _Assoc : association [cardinality] to TargetEntity on CondExp [with default filter CondExp ]   ];

   [  _Comp : composition [cardinality] of TargetEntity   ];

   [  [@element_annot]
      _ParentAssoc : association to parent Parent on CondExp   ]; 
}
```

A CDS custom entity can be used as follows:
- **ABAP CDS**: as the association target, CDS composition, or CDS to-parent association. But,this can be used only in a FIORI Odata Scenarios where the RAP Query Engine (not sql) is used to execute the query.
- **ABAP Programs**: we can use the custom entity after the 'TYPE' and the a attributes of the structured type can be evaluated using RTTI.
Hint: we cannot do a select on the custom entity, or used by path expression in ABAP SQL.
- **RAP Framework**
Custom entities are used as a data model basis for RAP unmanaged queries.   
See more info in the section 10c(<< add link to section c >>) or [Unmanaged Queries](https://help.sap.com/viewer/923180ddb98240829d935862025004d6/Cloud/en-US/254f68c7d5374e94a88241b7ce3bd414.html) . 


Hints and important informations!
- **Client handling is not defined** because and instance of a CDS custom entity is not created as a database object.
- **No DCL support for custom entities**: If required, access control needs to be implemented manually in the query implementation class.
- **CDS metadata extensions are not supported**.
- Custom entities **can be nodes in RAP business objects**, for example root, parent and/or child nodes using ROOT and composition relationships.

In the context of the ABAP RESTful Application Programming Model, the data model for an unmanaged query can be defined in a CDS custom entity, this custom entities defines the structure of the data returned by the query.  
The ABAP query is in this case executed by a framework such as the RAP query engine.

Unnmanaged Query: is implemented for read-only access to a data source when the data is not stored in a database table or SQL push-down by the query framework is not sufficient.

Use cases for unmanaged queries are  
- the data source for an OData request is not a database table, but, for example another OData service, which is reached by an OData client-proxy.  
- performance optimization with application specific handling.  
- using AMDPs with some query push-down parameters in the SQL script implementation.  
- forwarding the call to the analytical engines, or  
- enrichment of query result data on property or row level, for example when splitting rows for intermediate sums or condensing the filter result.  

> Hint!  
- If a custom entities is having annotations these can be evaluated using the methods of the class `CL_DD_DDL_ANNOTATION_SERVICE`.  
- If a custom entities has parameters or associations these would be evaluated by frameworks such as the RAP query engine.

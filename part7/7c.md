# Part 7c - Adding a Side Effect via Guided Development

## Intro: Side Effects
Side Effects allow the FrontEnd application to understand dependencies between fields. For example, the app can be told to automatically refresh specific fields when a certain value was changed and others are dependent on this. To find more information, visit [SAP Help Portal: Side Effects](https://help.sap.com/docs/ABAP_PLATFORM/468a97775123488ab3345a0c48cadd8f/18b17bdd49d1436fa9172cbb01e26544.html?locale=en-US). 


## Implementation
Luckily, SAP provided a Guided Development wizard for Side Effects within the BAS and of course, we will use this one. We want the TotalPrice to be automatically updated when the user changes the BookingFee. Normally, this would only happen when actually saving the Travel on its Object Page. But with a Side Effect, the refresh will be done in draft mode when the user modifies the booking fee and leaves its input field. The UI will be busy for a moment and the refreshed TotalPrice be shown already.

To start the configuration, right-click your *webapp* folder and select *Start Guided Development*. Search the existing guides for "side effect" and start the guide *Object Page > Configure side effects*.  

In step 1, select the Entity Type *TravelType*.  
Proviide the Qualifier *RefreshTotalPrice*.  
Choose the Source Property *BookingFee*, click *Insert Snippet* and then  *Next >*.

In step 2, select the Target Property *TotalPrice* and then click on *Insert Snippet*.  
You can now click *Exit Guide* annd check the local annotations in the newly created file *annotations.xml*. When you start the App Preview, the side effect will already work as expected!
